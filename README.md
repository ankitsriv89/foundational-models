# foundational-models

A growing collection of foundation models built from scratch — to understand, not just to use.

Each sub-project is self-contained: its own code, configs, docs, and write-up. They share a philosophy:

- **Readable over clever.** Code reads top-to-bottom like a tutorial.
- **Modern over canonical.** 2025-2026 architecture choices, not 2018 GPT-2.
- **Documented decisions.** Every architectural choice has a written justification.
- **End-to-end.** Tokenizer → data → training → eval → serving — not just the model file.

To answer the interview question "have you ever built a transformer from scratch?" with code, model cards, and loss curves — not just a yes.
